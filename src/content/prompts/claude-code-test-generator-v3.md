### Claude Codeでの実行方法

ターミナルで以下のようにファイルパスを指定して実行するだけで、テストファイル作成から実行確認まで完了します：

```bash
claude "src/utils/calc.ts の単体テストを Vitest で網羅的に作成し、tests/calc.test.ts に保存してテストを実行して"
```

テスト実行で落ちた場合も、Claude Codeが自動でコード側またはテスト側の修正を提案してくれます。
